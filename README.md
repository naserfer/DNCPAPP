# DNCPAPP

En producción: https://contratos-abiertos.pages.dev

Web app gratuita y de acceso inmediato para buscar y seguir proveedores, instituciones y licitaciones públicas de Paraguay, con enlace al proceso oficial de la DNCP.

Proyecto de [Ardentium](https://ardentium.tech/). Estado: **fase 0 (descubrimiento)**.

- Plan del proyecto: [PLAN.md](PLAN.md)
- Auditoría del plan: [AUDITORIA.md](AUDITORIA.md)

## Configuración

Copiá `.env.example` a `.env` y completá las credenciales. El archivo `.env` nunca se sube al repositorio.

## Datos

Los datos provienen del Portal de Datos Abiertos de la Dirección Nacional de Contrataciones Públicas (DNCP), publicados bajo licencia [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Esta herramienta reproduce datos oficiales y no afirma irregularidades.
